Server Tidak Dapat Dimulai

Aplikasi gagal terhubung ke backend server.

Kemungkinan MySQL belum berjalan atau konfigurasi salah.

Langkah perbaikan:
1. Pastikan MySQL / XAMPP sudah aktif
2. Cek file .env di folder backend
3. Pastikan database absen_wfh sudah dibuat
4. Klik tombol di bawah untuk coba lagi
